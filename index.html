    Latest October 18, 2026

    v1.2.2

    Custom Hub greeting names, configurable timezone selection, tiered Google AI Overview blocking (Deep Block vs Visual Hide), Wiktionary fallback for native dictionary definitions, address bar autofill click fixes, and high-severity security patches.

    New features Hub Personalization & Timezones
    • Personalized Hub Greeting Name

      Set your own name in Settings > Hub to have the Hub clock greeting address you personally (e.g. "Good Morning, Alex"). Seamlessly supports all translations.

    • Custom Timezone Selection

      Choose your preferred timezone in Settings > Hub. Both the clock display and the time-of-day greeting automatically recalculate according to your chosen region.

    • Tiered Google AI Overview Blocker

      Choose between Deep Block (server-level Web mode via &udm=14, completely stopping Google from generating AI on their servers), Visual Hide (in-page cosmetic hiding; note that Google still generates the AI overview in the background, but Leef hides it from view to preserve calculators and search widgets), or Off.

    Bug fixes Browsing & Search Enhancements
    • Google AI Overview Toggle Unblock Fix

      Fixed an issue where toggling off the AI Overview blocker left injected hiding styles active in Google Search tabs. Toggling the setting now immediately restores AI Overviews across all current and future tabs.

    • Native Dictionary Offline & Hang Prevention

      Resolved dictionary lookup cards getting indefinitely stuck on "Fetching definition…". Added a 3.5s timeout and automatic fallback to Wikimedia Wiktionary's fast, global CDN endpoint.

    • Address Bar Autofill Click Navigation

      Fixed an issue where clicking on a suggestion in the autofill dropdown dismissed the popup without navigating due to premature input blur. Added mousedown default-prevention to guarantee clean navigation.

    • Fast Typing Enter Key Submission

      Fixed a race condition when typing quickly in the search bar and pressing Enter where the first suggestion would override or drop the last character typed.

    • Linux Primary Selection Auto-Paste Fix

      Fixed an issue on Linux where closing a tab and transitioning to a new tab or hub automatically pasted whatever text was highlighted on the OS into the address bar or search input without copying.

    Security Dependency & Engine Hardening
    • High-Severity Dependency Vulnerability Resolution

      Resolved 20 high-severity security vulnerabilities across dependencies including Electron runtime fixes (context isolation hardening, sandboxed iframe popups, and cross-origin checks), builder-util-runtime, ip-address, postcss, and extract-zip.

    October 15, 2026

    v1.2.1

    Cryptographic build provenance, automated release checksums to verify downloads match the source code, and a fix for macOS fullscreen window restoration.

    Security Build & Download Verification
    • Cryptographic Release Checksums

      Every Leef release now includes automated SHA-256 checksums (SHA256SUMS.txt) so users can mathematically verify that their downloaded installer was not altered or corrupted.

    • GitHub Artifact Attestations (SLSA)

      Releases are cryptographically attested via Sigstore and SLSA framework, providing an official verified badge proving that the download came directly from the exact commit in the source repository.

    • Direct ASAR Inspection Guide

      Added comprehensive documentation showing how anyone can unpack the application bundle and inspect the running code line-for-line against the open-source repository.

    Bug fixes macOS & Stability
    • macOS Fullscreen Restoration Fix

      Fixed a bug on macOS where exiting fullscreen (such as full-screen HTML5 video or window zoom) caused Leef to stay locked and not revert back to its normal layout.

    • macOS Build Compatibility

      Configured macOS Universal builds with relaxed identity discovery so pulling and building locally on macOS works smoothly without keychain code-signing conflicts.

    v1.0.0

    Stable

    Cross-platform macOS & Linux support
    • Leef is now on macOS

      Mac users can now download Leef as a native .dmg installer. The browser automatically detects that it's running on a Mac and adjusts its layout so nothing overlaps with the system window controls in the top corner.

    • Leef is now on Linux

      Linux users can install Leef via AppImage — no package manager needed, just download and run. The browser uses a clean custom title bar with its own minimize, maximize, and close buttons, and has smooth rounded window corners on supported setups.

    • Smarter Linux system info

      When something goes wrong on Linux, Leef now correctly identifies your specific distribution in logs and bug reports — so instead of a generic "linux," you'll see something like "Ubuntu 24.04 LTS."

    Languages Multi-language support
    • French, Spanish & Dutch

      Leef is now available in three new languages.

    • Better regional language detection

      Leef now correctly recognises regional language variants when browsing, including British English, Canadian English, Dutch, French and Spanish, so websites respond in the right language more often.

    Interface Complete redesign
    • Redesigned settings

      The settings menu is now completely reorganized with proper tabs, so finding what you're looking for is actually straightforward instead of buried in a massive wall of options.

    • Redesigned site info popup

      The site information panel now matches the rest of the redesigned interface, giving you connection and security details in a clearer, more consistent layout.

    • Better hub tile creator

      The home hub tile creation popup is completely redesigned and now lets you pick a custom color for your tiles. We also fixed a bunch of bugs that were hanging around.

    • Redesigned scrollbar

      The scrollbar now looks like it belongs to Leef instead of using Chromium's generic default, matching the rest of the app's visual design.

    • Better loading states

      Loading indicators are now more obvious and easier to spot, so you always know when a page is still loading.

    • Improved autofill animations

      Search autofilling now has some more smooth animations and shouldnt blink every time you put in a new letter

    Features New & improved
    • Built-in dictionary

      Google removed their dictionary from search results, so Leef built one in. Now when you search for a word, you'll see a definition right at the top without having to open another tab.

    • Quick access to help

      A new button in the quick menu takes you straight to the FAQ and troubleshooter on the website, so you can solve problems faster.

    • Much better Google search results

      Our AI removal and Google page improvements are working way better now. You'll see proper info boxes again, and the "People Also Ask" section won't show up empty. This is the one most users will notice right away.

    • Google search crash workaround

      We found and fixed a bug that would crash Leef when you searched certain terms on Google. For now, those searches fall back to DuckDuckGo automatically while we work on a permanent fix.

    • Windows security popup blocker

      Some sites try to open Windows security popups (like Windows Hello) without asking. Leef now intercepts these and asks for your permission first before letting the popup through.

    Performance Speed & stability
    • Fixed video CPU spike

      Leef was using a lot of CPU if you left video pages paused for too long. That's fixed now — your computer will stay cool even if you leave YouTube open for hours.

    Security Under the hood
    • Stricter internal boundaries

      We've tightened up the wall between what the browser's interface can and can't do. Only a specific, hand-checked list of actions are allowed through — everything else is blocked by default.

    • Closed a potential security gap

      Fixed an edge case where a compromised web page could theoretically have tricked Leef into running unintended code. It was never exploited, but we closed it anyway.

    • Safer file handling

      Leef now double-checks all file paths for downloads, logs, and screenshots to make sure they always end up exactly where they should — no funny business with path trickery.

    • Dependency security fixes

      Updated two internal packages that had known vulnerabilities. Neither affected normal browsing, but we don't like leaving things unpatched.

    Build Packaging & distribution
    • Automated platform builds

      We've set up dedicated build pipelines for Windows, macOS, and Linux so that each platform gets a properly packaged installer every release — no manual steps, no missed platforms.

    The Leef Story

    Leef was designed in 2022 as a proof of concept and was originally just a very basic web page, not a standalone browser. Around 2023, you would go there instead of google.com. It was popular in a small group of about 30 people, but eventually, it was abandoned.

    Development on the full browser started in July 2025, and it was released into public alpha in April 2026. It was made to be a fast and AI-free alternative to Google.

    Every browser company is adding AI slop to their browser. I got tired of it, so I made the opposite: a no-AI browser.

    Global Privacy Control

    What is Global Privacy Control (GPC)?
    GPC is a legal browser signal that automatically tells websites you want to opt-out of having your personal data sold or shared. Under laws like California's CCPA and Europe's GDPR, participating websites are legally required to respect this signal.

    Search Engine Safe Mode

    Preventing search engine crashes

    Google recently changed its search engine backend to prioritize its "AI Overview" features. Because Leef injects specialized filters to strip out these AI components, the complex scripts served by Google can conflict with our blocker, causing the underlying Chromium layout engine to crash.

    To keep your browsing seamless and avoid infinite crash loops, Leef automatically loads your query in Safe Mode using DuckDuckGo.
